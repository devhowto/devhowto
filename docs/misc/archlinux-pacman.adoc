== Error: not enough free disk space

[source,text]
----
$ aur sync --upgrades && \
  sudo pacman --sync --refresh --sysupgrade

(redacted output)

:: Proceed with installation? [Y/n]
error: Partition / too full: 400344 blocks needed, 39166 blocks free
error: failed to commit transaction (not enough free disk space)
Errors occurred, no packages were upgraded.

The solution is to clean the pacman cache.

[WARNING]
==== 
Clearing the pacman chache right before a system upgrade is dangerous.
If something goes wrong and for example, we might need to downgrade to a previous kernel version, it will no longer be available in the local cache.

See:

* https://wiki.archlinux.org/title/Downgrading_packages
* https://wiki.archlinux.org/title/Pacman#Cleaning_the_package_cache
====

[source,shell-session]
----
$ sudo pacman --sync --clean --clean
[sudo] password for devy:

Cache directory: /var/cache/pacman/pkg/
:: Do you want to remove ALL files from cache? [y/N] y
removing all files from cache...

Database directory: /var/lib/pacman/
:: Do you want to remove unused repositories? [Y/n] y
removing unused sync repositories...
