== Directory X already exists

.With aur version 20.5.8 in 2026
[source,shell-session]
----
$ aur sync --upgrades

...
==> Extracting sources...
==> Starting prepare()...
Creating directory NVIDIA-Linux-x86_64-580.178.04
The directory 'NVIDIA-Linux-x86_64-580.178.04' already exists.  Please either
move the existing directory out of the way, or specify a
different directory with the '--target' option.
==> ERROR: A failure occurred in prepare().
    Aborting...
...
----

One option is to use the `--force` option:

.Excerpt from man aur-sync
[source,text]
----
-f, --force
       Continue  the build process if a package with the same
       name exists. (aur build -f)
----

== Remove package from repo

Even if we uninstall a package like `sudo pacman --remove pkg-name`, `aur sync --upgrades` will continue building it when new versions are available.
Therefore, we may also want to remove it from our custom aurutils repository.

So, if the repository DB is in ++/home/aurpkgs/aurpkgs.db.tar.gz++, the command to remove it is:

[source,shell-session]
----
$ repo-remove /home/aurpkgs/aurpkgs.db.tar.gz pkg-name

==> Extracting aurpkgs.db.tar.gz to a temporary location...
==> Extracting aurpkgs.files.tar.gz to a temporary location...
==> Searching for package 'pkg-name'...
  -> Removing existing entry 'pkg-name-0.3.0-1'...
==> Creating updated database file '/home/aurpkgs/aurpkgs.db.tar.gz'
----
